# SilentSpeak

Visual-only sentence transcription using lip-reading and deep learning.

## Current Status

- Auto-AVSR pretrained visual inference is working.
- GRID dataset is being used for development and evaluation.
- RTX 4050 GPU environment configured.
- WER/CER evaluation pipeline tested.

## Project Goal

SilentSpeak aims to convert silent video of a speaking person into text using visual speech recognition.
